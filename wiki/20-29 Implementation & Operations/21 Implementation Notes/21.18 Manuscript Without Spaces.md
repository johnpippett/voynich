# 21.18 Manuscript Without Spaces

## Result and decision

The fixed Latin substitution pilot failed its rule for a later reading study.
The ZL held-out mean cost was 4.421693, above the Latin baseline of 2.708901.
It was below both shuffled controls and the identity score. Lower costs fit this character model better.
The fixed rule required every condition to pass, so this version stops.
No validated Voynich key or translation resulted.

The [report](../../../reports/SPACEFREE_MANUSCRIPT_PILOT.md) gives the results, source limits, and replay commands.
The [method](../../../docs/plans/spacefree-manuscript-pilot-v1.md) and ten-file freeze preceded the first real calibration.
It is a separate experiment after the [23-letter control](21.17%20Substitution%20Without%20Spaces.md).
It does not restart or change the earlier stopped branches.

## Method and limits

All four new artificial controls recovered 23 observed assignments and every test character under a 26-letter model.
Their unused assignments differ from the planted maps. The complete alphabet was not recovered.
The controls share the same Latin model and text samples.
Their 23 fitting labels do not cover all 24 normalized signs in ZL fitting.

The runner fits complete eligible ZL training streams without recorded spaces.
It uses the existing parser's lowercase tokens. Uppercase EVA connection notation loses its case distinction.
The selected units are normalized code points, not a validated physical-sign inventory.
The same saved observed-data map applies to IT without another fit.

One ZL test `v` was absent during fitting. It stays unmapped, and all four affected windows remain in the score.
The two shuffled controls supply descriptive comparisons, not a false-positive estimate.
The baseline threshold is a fixed follow-up rule. Its failure does not show that the manuscript is not Latin.
The pilot did not test every possible substitution method or key.
The finite search proves no global optimum. The exposed data and metadata-based groups keep this study exploratory.

## Verification and operation

The new synthetic end-to-end checks and the existing substitution checks passed.
The required project suite passed all 85 tests.
All 56 restart score comparisons passed their fixed numerical tolerances.
A separate tree with fresh, hash-verified sources reproduced all 14 output files with identical bytes.

An independent direct-count audit passed after comparison of the source data, scores, and failed follow-up rule.
It independently scored all 56 saved restart keys. All seven best-score drift comparisons also passed.
This audit shares the pinned source loaders. It supplies no independent evidence for manuscript meanings.

The new command has a fixed 1,800-second limit and a POSIX alarm.
Its CI check uses synthetic data and needs no source download.
Original sources remain in ignored data directories. Decoded text, detailed loci, and model counts remain in ignored results.
The public aggregate contains maps, counts, costs, configuration, and hashes.

An internal timeout has error type `TimeoutError`, but its stage can be `runtime`.
During an incomplete manuscript stage, `not_started` can remain after source loading has begun.
That intermediate label cannot prove that manuscript data were never opened after a successful calibration.
Use the completed result, error receipt, and kept artifacts to identify the outcome.

## Rollback and continuation

Keep the frozen method, code, and results unchanged.
Record corrections in a new commit. Use a new method version for changed data, settings, scoring, or acceptance rules.
Do not extend this failed pilot with more restarts or a selected passage.
The research objective remains unresolved. A new study needs a separate question and fixed method.
