# Celsus reference partitions

## What changed

Added an adapter for the accepted Celsus paragraph projection.
It extracts alphabetic runs, retains adjacent combining marks, and applies the existing word normalization.
It assigns complete chapters to training, validation, and test partitions within each book.
It removes exact normalized paragraph duplicates from later partitions.
It preserves duplicates within one partition.
Added a fixed wrapper with an external 18-file hash manifest.
The wrapper checks all source bytes before adapter import or paragraph parsing.

The [control plan](../../../docs/plans/celsus-reference-control-v1.md) fixes the source, split, token rules, and later search limits.
The accepted extraction remains documented in [the projection report](../../../reports/CELSUS_PROJECTION.md).

## Why

The existing Latin control uses legal charters. The Italian control uses one poetic work.
Celsus adds one ancient medical work for a descriptive comparison.
It does not isolate language from author, period, genre, or editorial differences.
The control cannot identify the language or subject of the Voynich manuscript.

## Verification

Ten synthetic adapter tests pass.
Review found that parsing a chapter key could merge book identifiers containing a colon.
The adapter now uses validated book identifiers directly.
A regression test keeps two such books in separate split groups.
Nine wrapper tests cover input hashes, acceptance, output paths, and deterministic records.
Review found that an internal path helper accepted parent-directory components.
The helper now rejects these components before directory creation.
The public manifest contains counts, source locations, and hashes without text or token arrays.
The first GitHub run found a test dependency on local source files.
The revised tests use synthetic bytes for every pinned input.
All 54 medical tests pass in a clean checkout without the source cache.
The revised pre-run manifest changes only the test-file hash.
The [initial manifest](../../../experiments/medical/partition-freeze-v1-initial.json) preserves the earlier record.
The first source run followed successful GitHub checks at commit `afcb1f2a959f57f902c779f6bd16e882ab894d4e`.
It retained all 550 paragraphs and produced 101,715 normalized word tokens.
Training, validation, and test contain 62,423, 12,145, and 27,147 word tokens.
A fresh public checkout rebuilt the projection and reproduced all three output files.
A separate standard-library calculation reproduced all private arrays and the complete adapter manifest.
Root review corrected its Unicode combining-mark rule before publication. The measured arrays did not change.
The [partition report](../../../reports/CELSUS_PARTITIONS.md) links the manifest, replay, and independent audit.
No cipher model ran in this stage. The published manifest fixes the later model input.
