# 21.19 Common Visual Units

## Inventory result

The fixed six-compound tokenizer gives 30 distinct analysis labels in the complete eligible ZL training cohort.
A total injective map from those 30 labels to 26 letters is impossible.
The IT training cohort has 26 labels. That count alone does not prove a key or rule out this map size.

The [inventory report](../../../docs/research/visual-unit-inventory-2026-09-30.md) gives all six partition counts and source limits.
It uses the same eligible words and source groups as the stopped [raw-EVA pilot](21.18%20Manuscript%20Without%20Spaces.md).
The normalized labels describe an analysis representation. They need not be linguistic letters or indivisible physical signs.

## Source-defined common list

Smith and Ponzi's July 2018 preprint lists 23 common forms.
That fixed list covers 99.8032 percent of ZL training units and 99.8023 percent of IT training units.
All 23 forms occur in both training partitions. Every outside unit stays in the denominator.
The list supplies no letter values. Coverage is not reading accuracy.

The list can define a separate partial-map question.
Any such experiment must keep unknown positions, fix its method before fitting, and pass artificial controls first.
This inventory count did not fit a key or change the earlier stopped studies.

## Fixed partial-map pilot

The [new method](../../../docs/plans/common-visual-pilot-v1.md) fixes one injective map from the 23 common units to 26 Latin letters.
Every outside unit stays unknown. Every affected four-unit window stays in the score at constant cost `log2(26)`.
The method reports both unit coverage and normalized EVA code-point coverage, with all outside positions in the denominators.
It keeps each source spelling, case, logical position, and complete logical record in private evidence.

Four artificial controls must pass before manuscript loading.
These controls use full 26-position permutations. Their 23 observed fitting labels come from the fixed Latin sample without letter filtering.
The manuscript test fits observed ZL text and two fixed shuffles.
It then applies the saved observed ZL map to IT without another fit.
All follow-up conditions must pass before a separate reading study can be considered.

The synthetic command checks and all 85 required project tests passed before the freeze.
