# 21.04 Complete Optimal Sets

## Change and reason

The Latin control has a certified dictionary score, but its selected map contains one ambiguous assignment.
The next experiment will retain all equally scoring maps in the fixed finite domain.
It will then compare them with a fixed character model trained only on training text.

The [protocol](../../../docs/plans/optimal-set-secondary-v1.md) fixes inputs, limits, exact arithmetic, ties, and output order.
The [component guide](../../../experiments/optimal_set/README.md) explains the two new primitives and their source-bound runner.
This work does not change the earlier failed checks or establish a manuscript reading.

## Verification

Separate synthetic calculations check the enumerator and exact likelihood ratios.
The enumerator review checked 3,750 random target cases.
The ranking review checked 3,150 candidate scores across 150 models and three capacity settings.

Review found that malformed model tables could change a tie into a false winner.
The corrected validator checks table coverage, counts, totals, contexts, vocabulary, and control symbols before scoring.
Regression tests retain that failure case.

The runner checks proof records, complete candidate sets, exact ties, canonical ratios, source hashes, and the fixed protocol hash.
Review corrected incomplete-query handling, missing source hashes, unsupported proof records, and a misleading partial-result field.
Test diagnostics now count unseen symbols as errors in the full denominator.

All 262 core and experiment tests pass, including 34 optimal-set tests.
The [runner review](../../../experiments/optimal_set/RUNNER_REVIEW.md) records the final checks and source hashes.
Commit `883da35809cb1a3828876f272f108ae103fdf98a` published the protocol and implementation before the first development run.
Its GitHub checks passed before that run.
