# Cyclic emitter pairing

## What changed

Added a compatibility graph for the fixed capacity-two control emitter.
Each candidate edge joins two units whose projected occurrences alternate.
Added bounded perfect-matching searches and edge-removal queries.
An edge-removal query can identify a pair required by every complete matching.

The [design note](../../../docs/research/cyclic-emitter-pairing.md) states the mathematical conditions and counterexamples.
The [control protocol](../../../docs/plans/cyclic-pairing-control-v1.md) fixes two validation streams and their input hashes.
The wrapper verifies a 28-file manifest before it starts a pairing process.
It limits each corpus to 300 seconds and a sampled 7 GiB memory threshold.
It writes aggregate records and keeps measured resource data private.

The [observed quotient note](../../../docs/research/observed-pair-quotient.md) separates identified observed classes from ambiguous unseen pairs.
The [segmented design](../../../docs/research/segmented-cyclic-emitter-design.md) defines limits for incomplete streams.
The [local obstruction note](../../../docs/research/local-cyclic-obstructions.md) gives necessary constraints for exact cyclic emitters.
The [quotient recovery plan](../../../docs/plans/cyclic-quotient-recovery-v1.md) defines a later development stage.
That stage has no control result or published implementation freeze yet.
Shared wildcard positions can invalidate separate pairwise repairs.
Those modes require a joint assignment method before any manuscript use.

## Why

The synthetic emitter has a constraint that the general dictionary search does not use.
Each plaintext letter alternates between two cipher units across word boundaries.
Pair recovery can test this constraint without assigning plaintext letters.
Unseen units can leave several full matchings even when observed pairs are fixed.

This method applies to the declared deterministic emitter.
It does not establish an encoding rule for the Voynich manuscript.
Removing uncertain text can break the alternation constraint.
A manuscript test would require a separate model for gaps and uncertain units.
