# Cyclic quotient recovery

Status: development stopped before any source fit. The manuscript-discovery priority supersedes the remaining wrapper work.

## What changed

Added a reference-control method that first proves which observed units belong to the same pair.
It combines each proved pair into one class before fitting plaintext letters.
The [recovery plan](../../../docs/plans/cyclic-quotient-recovery-v1.md) fixes this procedure.
The [run plan](../../../docs/plans/cyclic-quotient-run-v1.md) defines the outer command and resource limits.

The graph record retains all compatibility candidates and their recorded orientations.
After fixed observed pairs are removed, full residual matchings represent the possible unseen completions.
An isolated candidate edge is not a certificate that the edge has a full extension.
The fit assigns no unseen mate and selects no ambiguous observed relation.

The lexical solver receives only the training lexicon and transformed validation counts.
It uses capacity one over observed classes and no initial key.
The core saves the quotient, fitted key, and fit records with exclusive creation.
The child verifies the saved key before test encryption or accuracy comparisons.
Source identity comes from the outer input freeze and output hashes, plus direct diagnostics when available.

## Why

The earlier pairing control found one observed Latin relation and multiple observed Italian relations.
A letter search can use a proved relation without selecting one ambiguous completion.
This provides a control for a structured encoding with a known artificial source.
The local manuscript test already rejected that exact cycle on its two fixed unitizations.
The present reference study therefore does not supply a manuscript decoder.
