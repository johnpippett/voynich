# 21.16 Naibbe Relabeling Control

## Decision

None of the four artificial Naibbe relabeling controls met the full-key acceptance rule.
It found zero, one, or two correct assignments among the observed test labels.
The known map has a lower fit loss than the found map in each case.
Thus, the saved maps are not optima for this objective.
This finding does not reject Latin, Naibbe, or all possible keys.

The attempt stops without a manuscript experiment.
No manuscript file was an input to the control.
The project still has no validated manuscript key or translation.
The earlier stopped studies stay stopped.

## Method and limits

The [report](../../../reports/NAIBBE_RELABEL_CONTROL.md) defines the question, method, sources, and acceptance rules.
The control tests a hidden permutation of 23 logical labels from the fixed Naibbe tables.
It keeps only spans whose tokens each have one distinct inverse plaintext.
Ambiguous tokens, unsupported tokens, and block endings break spans. Spans shorter than eight characters do not enter the search.

The search uses the existing Latin character model and substitution code.
It uses the same source samples for four different keys.
The scope and program hashes were fixed before reference encoding and key search.
The pre-run review added full-label coverage and complete-map equality to the acceptance rule.
No parameters or seeds changed after the results.

Only 22.68–26.29% of source characters enter the selected test spans.
Each selected test sample has 21 of the 23 logical labels.
All those labels have fitted assignments, but most selected test characters are wrong.
The error counts are 2,012/2,134, 1,891/1,954, 2,083/2,154, and 1,858/1,858 for seeds 408–411.

The tables use features of Voynich text. Their compatibility with the manuscript is not independent evidence for Naibbe.
This control concerns artificial text and does not restore ambiguous tokens or original spaces.
The reference contains legal Latin, with limits on genre and spelling coverage.
A future search study needs a new fixed question, method, and known-key acceptance rule.

It used the saved language model. It did not independently build that model from raw reference text.
The first audit had format and path assumptions that needed correction. Its failed receipt stays in the local records.
These project checks are not external scholarly validation.

Do not replace a failed control with a different seed or changed settings.
Program changes affect only this experiment; the existing library modules are unchanged.
