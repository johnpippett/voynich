# Celsus model control

## What changed

Added a fixed model runner for the accepted Celsus reference partitions.
The [operational plan](../../../docs/plans/celsus-model-run-v1.md) defines the command, output checks, and resource limits.
The existing [reference plan](../../../docs/plans/celsus-reference-control-v1.md) supplies the statistical settings.
The external control manifest checks 43 files before the child starts.

The child runs the unchanged homophonic solver with capacity two and seed 7000.
It uses 1,000 search nodes, the bitset bound, and no warm start.
The child saves the fitted key before test diagnostics.
The wrapper allows 1,500 seconds and a sampled 7 GiB memory threshold.

## Why

The earlier Latin and Italian controls use different genres.
This control adds one ancient medical work with independently checked source partitions.
The experiment measures recovery on a known artificial cipher.
It does not identify a manuscript language or supply a translation.

## Verification

All 78 medical tests pass in a source-free checkout.
The new core and wrapper account for 24 of those tests.
Review found an exit race and incomplete output checks.
The corrections cover resource status, feasible planted-score bounds, key count, and complete code hashes.
The wrapper also rejects command options outside the fixed plan.
The frozen inner runner checks that the map covers every fitted symbol.
The outer wrapper relies on that assertion and does not independently rebuild the fitted symbol set.

The source partitions remain pinned to their published manifest and two private output hashes.
The initial command failed before the model started.
The CLI used an output-path constant before its assignment.
A subprocess regression now exercises the published command with a synthetic child.
The first manifest and failed launch record remain available.
The corrected run used the published freeze after repository checks passed.
The [result report](../../../reports/CELSUS_MODEL.md) records a 1,000-node incomplete search.
The saved map recovered 92,936 of 150,708 test characters and 3,675 of 27,147 test words.
All exact-recovery gates failed.
A fresh public replay reproduced all three model files.
A separate calculation confirmed scores and recovery measurements without repeating the search.

## Rollback

Keep the source projection, chapter partitions, and earlier controls unchanged.
Preserve any incomplete or failed model attempt.
A changed input, objective, seed, or search setting requires a new recorded protocol.
