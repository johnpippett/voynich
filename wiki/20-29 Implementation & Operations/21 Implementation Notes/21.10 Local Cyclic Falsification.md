# Local cyclic falsification

## What changed

Added a local test for the exact cyclic emitter on two fixed manuscript unitizations.
The [protocol](../../../docs/plans/vms-local-cyclic-falsification-v1.md) defines the source, word policy, and interpretation limits.
The raw track treats each lowercase EVA character as one unit.
The visual track uses the existing six-compound unitizer.
Each accepted word is a separate uninterrupted segment.

The extractor retains source spelling and offsets.
It rejects uncertain boundaries and complete candidates that contain excluded constructs or interior whitespace.
The runner verifies 13 pinned files before it imports the parser or core.
It writes four aggregate records with every repeat location and no raw word arrays.
The external supervisor allows 60 seconds for the full command.

## Why

An exact cyclic emitter with at least two distinct units per symbol cannot emit adjacent equal units.
This follows from cycle advancement and disjoint unit sets.
The test can reject that precise model without a dictionary or guessed key.
It cannot reject a model with different unitization, hidden emissions, or internal resets.

## Verification

All 29 focused synthetic tests pass.
They include 15 core tests, eight runner tests, and six existing unitizer tests.
An independent review checked the local proof, strict extraction, output fields, and real subprocess command.
The runner sums affected words separately for each source record because candidate indexes repeat across records.
Tests cover that boundary and ensure excluded constructs cannot create an accepted partial word.

The current stage has no source result or image review.
The public freeze and repository checks must precede the first source run.
Raw transcription files remain outside the public repository.

## Rollback

Keep all source hashes, unitizations, and exclusion rules fixed for this run.
Preserve partial output after interruption.
A changed transcription or model requires a new recorded run.
Image review can assess a saved certificate but cannot delete it from the original result.
