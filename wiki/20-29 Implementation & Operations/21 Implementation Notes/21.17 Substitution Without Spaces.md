# 21.17 Substitution Without Spaces

## Result and decision

All four planted substitution keys passed the fixed control without original spaces.
Each control recovered all 22 observed fitting assignments and all 8,192 test characters.
The complete 23-entry map also equals the planted map in each case.
The fitting sample has one unused label. The permutation rule fixes its value after the other 22 assignments are known.

This result answers a new question about a weighted character-context score on complete Latin streams.
The earlier Stage 2 controls kept original word boundaries.
The stopped Naibbe control used selected inverse spans and a different score. This result does not change its failure record.
This control contained no manuscript input.
A later [26-letter manuscript pilot](21.18%20Manuscript%20Without%20Spaces.md) failed its fixed follow-up rule.
The project still has no validated Voynich key or translation.

## Method and limits

The [report](../../../reports/SPACEFREE_SUBSTITUTION_CONTROL.md) gives the result, sources, and replay procedure.
The [fixed method](../../../docs/plans/spacefree-substitution-control-v1.md) and its freeze record preceded the real controls.
The method uses the pinned Latin LLCT partitions and four planted permutations.
It removes all original spaces and keeps every selected character.
The search receives no planted key, fitting plaintext, or test ciphertext.

The four keys share one fitting sample and one test sample.
The normalized streams can cross document boundaries within a partition.
The reference contains early medieval legal Latin. The score weights are fixed heuristic choices.
The result supplies no manuscript sign values, language identity, global optimum, or false-positive estimate.
Any manuscript experiment needs a separate fixed method and the project validation protocol.
