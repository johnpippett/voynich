# 21.01 Homophonic Controls

## Change and reason

The prototype permits several cipher units to represent one plaintext letter.
It tests a broader map class than the earlier injective lexical pilot.
It does not establish a manuscript reading.

Commit `ce8b626ab3cf8147829716f7828dff7fceba6cde` contains the implementation and
the [reference protocol](../../../docs/plans/visual-homophonic-pilot.md).
The first four reference runs compare cold and assisted searches on Latin and
Old Italian controls. Manuscript experiments remain deferred.

The prototype includes a scalar solver, a matching bitset bound, synthetic
keys, recovery metrics, ambiguity counts, and a character-model starting key.
The runner writes the selected key before it scores the test partition.

## Verification

Before publication, 85 core tests, 52 lexical tests, and 58 homophonic tests
passed. Internal reviews checked the bound, scoring, source hashes, and key
isolation. These checks establish no historical cipher mechanism.

Run the homophonic checks from the project root:

```sh
PYTHONPATH=src:. python -m unittest discover -s experiments/homophonic -p 'test_*.py' -v
```

The [component guide](../../../experiments/homophonic/README.md) gives the
reference commands. Use separate output paths. Preserve all failed controls
and resource stops in the research record.

## Rollback

Use the previous commit in a separate checkout to repeat the earlier pilot.
Keep existing reports and their source hashes. The new prototype does not
change the earlier core or lexical experiment modules.

## Run status

The protocol was published before the first new reference result.
Both Latin runs reached the same certified lexical optimum. They selected
the same map and missed four of 111,052 test characters.
At least four maps attain this optimum. All test errors use one unit outside
the positive lexical hits. The exact-decoding gates failed.

Both Italian runs stopped at 1,000 nodes with unequal bounds.
The cold run recovered 56,397 of 130,084 test characters.
The assisted run recovered 86,480 of 130,084. The exact search retained its starting map.
Both Italian exact-recovery checks failed. No new manuscript run has started.
