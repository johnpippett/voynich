# Local word-memory result

## What changed

Ran the existing exact-repeat and one-edit prediction models on both manuscript transcriptions.
Used the existing complete-line filter and physical-group split.
The [report](../../../reports/LOCAL_MEMORY.md) records the negative result and its limits.
The result files contain aggregate scores, validation choices, group scores, and conditional shuffle scores.

## Why

The test compared local word dependence with line vocabulary and word-length position effects.
Both exact-repeat models selected zero context weight.
The edit model supplied no useful order-specific prediction gain under the two controls.
We stopped this branch without further parameter changes.
We also stopped synthetic cyclic quotient development because it supplied no new manuscript constraint.

## Verification

The analysis checks both source hashes and the existing code hashes.
Validation choices were saved before test scoring.
The separate target-score loop matches the original score before the shuffle calculation.
Each shuffle preserves the first word and the exact multiset of target words.
The second control also preserves word length at every position.
The report does not claim a blind trial, historical mechanism, or decipherment.
