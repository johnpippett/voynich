# 21.03 Medical Reference Source Audit

## Change and reason

The current references contain legal charters and poetry. They do not represent medical prose well.
The [candidate note](../../../docs/research/medical-corpus-candidates.md) records three possible additional sources.
The [Hildegard audit](../../../docs/research/causae-ocr-audit.md) tests the first candidate's digital text quality.
The [Celsus audit](../../../docs/research/celsus-source-audit.md) checks a separate ancient Latin medical source.

The downloaded text has frequent recognition errors. It is not approved as a clean reference input.
The source remains a possible noisy-text sensitivity control after page-aware extraction.
The existing reference manifest, parser, and model results are unchanged.

The Celsus XML has eight books, 211 chapters, and 550 source paragraphs.
It remains a proposed ancient medical control after a fixed text extraction method passes review.
Its age does not match medieval Latin. It cannot replace the historical-date control.

## Verification

The OCR text and XML match the provider's MD5 and SHA1 values.
The source note also records project SHA-256 values.
The XML contains 267 page objects. Proposed book boundaries remain provisional.

A manual visual spotcheck found 74 matching words in 100 selected OCR tokens.
The selected tokens include headers, page numbers, and preface text.
This is not a representative accuracy estimate or a reproducible annotated dataset.
A separate visual check confirmed two sampled pages: 18 of 20 and 16 of 20 matches.

The provider marks the item as public domain. The note records the exact scope of that statement.
Private source copies remain in the ignored results directory.
No full text or scan is included in the public repository.

The [public Celsus audit script](../../../scripts/audit_celsus_source.py) retrieves four files at a fixed source commit.
It checks byte counts, Git blob hashes, and SHA-256 values.
The [aggregate receipt](../../../reports/celsus-source-audit.json) records structure, markup, and source evidence without text arrays.
Separate counts distinguish all body markup from markup inside selected paragraphs.
Eight Greek elements occur inside notes. They are removed with their containing notes.
Only 20 highlight elements have no excluded ancestor.
These are markup diagnostics, not measurements of projected text.

A fresh acquisition reproduced the public Celsus receipt byte for byte.
The receipt records a fixed source-review date and does not depend on execution time.
Changed existing files and failed aggregate checks stop the audit.

## Projection validation design

The [fixed projection protocol](../../../docs/plans/celsus-projection-v1.md) defines correction, exclusion, whitespace, and location rules.
The [implementation](../../../experiments/medical/README.md) compares two separate XML traversals.
The runner checks the source hash, eight-book structure, paragraph counts, and traversal agreement.
An external five-file manifest binds the protocol, implementation, and tests before source projection.
Full paragraphs and manual context remain private. Public records contain hashes, counts, locations, and status.

Synthetic review found a nested-correction boundary error. Both traversals now retain the selected branch tails in document order.
The runner keeps acceptance pending until all fixed manual checks are complete.
No pinned-source projection has run at this implementation stage.
Publish reviewed code and the manifest before the first source run.

## Projection result

The first source run used public revision `c1753fc1f71836f50ff7c6946d722dead07441a9`.
Publication and both GitHub test jobs preceded the run.
The two traversals produced identical records for all 550 paragraphs, 211 chapters, and eight books.
No projected paragraph was empty. All retained-boundary checks passed.
A separate clean public checkout reproduced all five output files byte for byte.

Three AI review tasks inspected the 30 fixed source locations.
Review found four incorrect feature-presence classifications in one checklist batch.
An addendum records the corrections. The original checklist, batch record, and initial pending receipt remain unchanged.
The corrections do not change source text or projection rules.

The [result report](../../../reports/CELSUS_PROJECTION.md) records acceptance and its evidence.
The public artifacts contain aggregate counts and hashes. Source paragraphs and manual context remain private.
This result checks one extraction procedure. It does not certify the edition or identify a manuscript language.
