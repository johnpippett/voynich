# Research status

The objective is to explain the Voynich manuscript's writing system and test whether its content is recoverable.
That objective remains unresolved.

The first research stage provides source records, tested analysis code, structural experiments, and a protocol for candidate readings.
The project does not have a validated key, plaintext language, or translation.

## Current evidence

The [findings report](reports/FINDINGS.md) contains the measured results and their limits.
The [source registry](docs/research/sources.json) records the literature used during this stage.
The [hypothesis registry](docs/research/hypotheses.json) records candidate model families and tests that can reject specific models.

Separate AI-agent tasks performed implementation and code review within this project.
These checks do not constitute external scholarly validation.
The original manuscript data remain essential for further research.

## Next research stage

The next stage requires matched historical-language reference texts and models with known, recoverable solutions.
It also requires a complete physical-sheet map and an image review of selected transcription differences.
A candidate method must specify its rules before evaluation.
It must report coverage, exceptions, uncertainty, and unsuccessful tests.

The public repository contains research results and methods.
Private attachment metadata and personal information remain excluded.
