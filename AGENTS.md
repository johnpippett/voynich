# Voynich research

This repository is public. Do not include personal information, private contact
details, local user paths, credentials, or attachment metadata.
Use a neutral research commit identity. Audit staged content before publication.
Publish useful research updates to the authorized GitHub repository when they
are ready. This standing permission applies only to repository research
updates.

Keep research reproducible. Keep source files and record their SHA-256 hashes.
Do not report a translation without a fixed method and independent validation.
Keep observations, interpretations, and hypotheses separate.
EVA symbols describe written shapes. Do not assume that they are linguistic letters.
Get separate authorization before you contact researchers, submit material, or purchase services.
Use Python standard-library code when possible. Run `PYTHONPATH=src python -m unittest discover -s tests -v`.
Use bounded Luna workers for independent tasks. Workers must not create other workers.
Apply ASD-STE100 writing rules to technical documents.
